# Campus Nexus

Campus Nexus is a full-stack web application designed to connect senior and junior students for sharing academic guidance and essential items within the campus community.

## Features

- User registration and login
- Academic question sharing
- Question answering
- Essential item posting
- Browse available items
- Remove posted items
- MongoDB database integration
- RESTful API-based backend
- Responsive web interface

## Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose
